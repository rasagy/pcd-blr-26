# Processing Community Day, Bangalore — Generative Logos

Five dynamic, generative logo options for PCD BLR, built with p5.js and interactive GUI controls for real-time parameter tweaking.

- [1](https://rasagy.in/pcd-blr-26/1/) — **Blue Pottery Mandala**: a mandala built from rotating pixelated tech-cursor icons
- [2](https://rasagy.in/pcd-blr-26/2/) — **Trail Type**: click-drag paints a "PCD / BLR / 2026" band stack that waves along the trail
- [3](https://rasagy.in/pcd-blr-26/3/) — **Letter Wave**: "PCD" and "BLR" repeat along curving paths, shrinking and fading as they trail away
- [4](https://rasagy.in/pcd-blr-26/4/) — **Radial Type**: a word list becomes concentric rings of text, each with its own angle and reading direction
- [5](https://rasagy.in/pcd-blr-26/5/) — **Type Rotate**: "PCD • BLR" fans out clockwise from the center dot as fading radial trails
