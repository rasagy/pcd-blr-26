# Processing Community Day, Bangalore — Generative Logos

Five dynamic, generative logo options for PCD BLR, built with p5.js and interactive GUI controls for real-time parameter tweaking.

- [1](1/index.html) — **Blue Pottery Mandala**: a mandala built from rotating pixelated tech-cursor icons
- [2](2/index.html) — **Trail Type**: click-drag paints a "PCD / BLR / 2026" band stack that waves along the trail
- [3](3/index.html) — **Letter Wave**: "PCD" and "BLR" repeat along curving paths, shrinking and fading as they trail away
- [4](4/index.html) — **Radial Type**: a word list becomes concentric rings of text, each with its own angle and reading direction
- [5](5/index.html) — **Type Rotate**: "PCD • BLR" fans out clockwise from the center dot as fading radial trails

Serve over HTTP (not `file://`) and open `http://localhost:8000/<n>/index.html`:

```bash
python3 -m http.server 8000
```
